# Qibla Mobile

React Native version of the existing Qibla web pages, built as an Expo app.

## Run

```bash
cd mobile
npm install
npm run start
```

The auth screens call the Next.js API at `http://localhost:3000` on iOS/web and `http://10.0.2.2:3000` on the Android emulator. Start the web app from the repository root with `npm run dev` when testing login or register.
